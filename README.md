# ALF PET

A small offline virtual-pet Android game using the supplied 4x2 idle sprite sheet, split into 8 frames at 384x384 each.

## Features
- 8-frame idle animation
- Hunger, happiness, energy, cleanliness, health
- Coins and XP/levels
- Feed, Play, Sleep, Clean, Pet, Random actions
- Offline stat decay while the app is closed
- Local save using SharedPreferences
- No external runtime dependencies

## Build
GitHub Actions workflow: `.github/workflows/build.yml`
