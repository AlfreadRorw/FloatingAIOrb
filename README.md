# Retro Platformer Android

Project Android Kotlin siap dibuka di Android Studio.

Fitur:
- Landscape
- Kontrol kiri, kanan, lompat
- Side scrolling camera
- Karakter original
- Coin dan bonus block
- Platform rumput
- Pipa hijau
- Musuh blob
- Score, nyawa, stage, timer
- Collision dan gravity

Build:
./gradlew --no-daemon clean assembleDebug

Catatan:
Visual dibuat sebagai game platformer retro original. Tidak memakai karakter, nama, atau aset Mario berhak cipta.
