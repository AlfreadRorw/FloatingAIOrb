ALF DOWNLOADER - TERMUX SETUP

1) termux-setup-storage
2) cd ke folder termux-server ini, lalu:  bash install.sh
   (install.sh sudah mengaktifkan allow-external-apps=true)
3) Restart Termux sekali.
4) Buka ALF Downloader dan izinkan "Run commands in Termux environment".
5) Server menyala otomatis. Manual: bash ~/alf-downloader-server/start.sh

Tes: curl http://127.0.0.1:8080/api/health
Log server (jika dijalankan dari aplikasi): ~/.alf-server.log
