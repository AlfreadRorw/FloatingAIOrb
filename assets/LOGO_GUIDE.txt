WHATSSTATUS VAULT - ASSET GUIDE

APP ICON
- Preferred master: PNG, 1024 x 1024 px, transparent background.
- Keep the important logo shape inside roughly 720 x 720 px so Android masks do not crop it.
- Monochrome black/white is recommended for the current theme.
- If you want an Android adaptive icon later, provide:
  foreground: 432 x 432 px PNG (transparent)
  background: solid black or white

DOCK ICONS
- Status: 96 x 96 px PNG, transparent, monochrome.
- History: 96 x 96 px PNG, transparent, monochrome.
- Settings: 96 x 96 px PNG, transparent, monochrome.
- Vector drawables are preferred when possible for sharpness on every phone.

WHERE TO REPLACE
- App placeholder icon: app/src/main/res/drawable/ic_app_logo.xml
- Dock icons: app/src/main/res/drawable/ic_status.xml
  app/src/main/res/drawable/ic_history.xml
  app/src/main/res/drawable/ic_settings.xml

For PNGs, rename them to lowercase resource names such as app_logo.png and update AndroidManifest.xml.
